# Development runs (package v1.2)

Two runs on a Colab T4, made with package v1.2.1 (scoring version 11, which v1.2.5 keeps); tables remade with
v1.2.5. Readers and models in fp16. Summary: [docs/results.md](../../docs/results.md); values of the confirmatory
statistics: [docs/PROTOCOL.md](../../docs/PROTOCOL.md#development-values). The LLM judge and Selective Context are
added by `colab/dev_baselines_a100.ipynb` (not yet run). The v1.0 runs: [results/dev_v1.0](../dev_v1.0/README.md).

| | Synthetic (`t4_n20_v12/`) | Real texts (`real_t4_n15_v12/`) |
|---|---|---|
| Items | 300: 15 cells × 20 | 312: 21 cells × 15 (MS MARCO 12) |
| Models | Qwen2.5-0.5B, Qwen2.5-1.5B, SmolLM2-1.7B (Instruct) | same |
| Prompts | default, "Be concise." | same |
| Decoding | plain greedy, at most 320 new tokens | same |
| Responses | 1800 | 1872 |
| Reader | Qwen2.5-3B-Instruct | Qwen2.5-3B-Instruct |
| Second reader | – | Phi-3.5-mini-instruct |
| Seed | 0 (planted-filler check: 2026) | 0 |

## Files

| File or folder | Contents |
|---|---|
| `tables_synthetic.md`, `tables_real.md` | all tables: checks, baselines, results per model, "Be concise.", item design, missing facts, entropy, reader agreement |
| `items.jsonl` | items: source text, request, facts with accepted answers, gold answer, design |
| `responses.jsonl` | model answers: `item_id`, `model`, `variant`, `response`, token count, generation settings |
| `scored.jsonl` | answers scored by the main reader: `info`, `W` (removable), `W_filler` (filler), `W_misleading` (wrong), `kappa` (completeness), `facts`, `overhead`, `added_answers`; `spans`: `kept`, `kind`, `loo_cost` |
| `signals.jsonl` | entropy of the generating model per fragment |
| `reader2_phi-3.5-mini/` | the same with the second reader |
| `filler_check/`, `filler_check_real/` | planted filler: synthetic reports (T1, R2), real texts (R3) |
| `real_t4_n15_v12/human_check/` | filler map vs the human span labels of Poddar et al. (R4) |
| `real_t4_n15_v12/filter_report.json`, `config.json`, `hardware.json` | leakage filter per cell; settings and dataset sha256; GPU and libraries |
| `report/` | tables as CSV, figures |

`real_t4_n15_v12/items.jsonl` (sha256 `77358dc937769f9486b0fbb13e7af2195d6c45ad45c8aa874c0a1cf30d9d8ccc`) is one of
the two items files whose source texts the confirmation run leaves out.
