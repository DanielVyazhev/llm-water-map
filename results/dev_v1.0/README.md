# Development runs (package v1.0.0)

Two runs on a Colab T4. Tables rebuilt with v1.0.0; scores not recomputed: the synthetic run has scoring version 8,
the real-text run 7 (the two differ only on missing-fact items). Summary and caveats:
[docs/results.md](../../docs/results.md); worked examples: [docs/examples.md](../../docs/examples.md).

On real texts v1.0.0 did not credit part of the correct answers (answer written in other words). v1.1.0 fixes it;
these are still v1.0.0 scores, to be rescored ([docs/running.md](../../docs/running.md#rescoring)).

| | Synthetic (`synthetic/`) | Real texts (`real/`) |
|---|---|---|
| Items | 300: 15 cells × 20 | 312: 21 cells × 15 (MS MARCO 12) |
| Models | Qwen2.5-0.5B, Qwen2.5-1.5B, SmolLM2-1.7B (Instruct) | same |
| Prompts | default, "Be concise." | same |
| Responses | 1800 | 1872 |
| Reader | Qwen2.5-3B-Instruct | Qwen2.5-3B-Instruct |
| Second reader | Phi-3.5-mini-instruct | Phi-3.5-mini-instruct |
| Seed | 0 | 0 |

## Files

| File or folder | Contents |
|---|---|
| `tables_synthetic.md`, `tables_real.md` | all tables: checks, baselines, results per model, "Be concise.", item design, missing facts, entropy, reader agreement |
| `items.jsonl` | items: source text, request, facts with accepted answers, gold answer, design |
| `responses.jsonl` | model answers: `item_id`, `model`, `variant`, `response` |
| `scored.jsonl` | answers scored by the main reader: `info`, `W` (removable), `W_filler` (filler), `W_misleading` (wrong), `kappa` (completeness), `facts`, `overhead`; `spans`: `kept`, `kind`, `loo_cost` |
| `signals.jsonl` | entropy of the generating model per fragment |
| `reader2_*` | the same with the second reader |
| `filler_check/`, `filler_check_real/` | planted filler: synthetic reports, real texts |
| `real/human_check/` | filler map vs the human span labels of Poddar et al. |
| `real/filter_report.json`, `real/config.json` | leakage filter per cell; settings |
| `report/` | tables as CSV, figures |
| `synthetic/paper/` | tables for the paper, a trial annotation sample |
| `examples/examples.json` | data of [docs/examples.md](../../docs/examples.md) |
