# Development runs (package v1.0.0)

These are two runs on a Colab T4. Their tables were rebuilt with v1.0.0 after its release. The scores themselves were not recomputed: the synthetic run was scored with scoring version 8 and the real-text run with version 7. The two versions give the same scores everywhere except on items with a missing fact.

| | Synthetic (`synthetic/`) | Real texts (`real/`) |
|---|---|---|
| Items | 300: 15 cells × 20 | 312: 21 cells × 15 (MS MARCO: 12) |
| Models | Qwen2.5-0.5B, Qwen2.5-1.5B, SmolLM2-1.7B (Instruct) | same |
| Prompts | default and "Be concise." | same |
| Responses | 1800 | 1872 |
| Reader | Qwen2.5-3B-Instruct | Qwen2.5-3B-Instruct |
| Second reader | Phi-3.5-mini-instruct | Phi-3.5-mini-instruct |
| Seed | 0 | 0 |

## Files

| File or folder | Contents |
|---|---|
| `tables_synthetic.md`, `tables_real.md` | Every table of the run: checks, baselines, results per model, "Be concise.", item design, missing facts, entropy, agreement between readers |
| `items.jsonl` | The items: source text, request, facts with accepted answers, gold answer, design knobs |
| `responses.jsonl` | Model answers: `item_id`, `model`, `variant`, `response` |
| `scored.jsonl` | Every answer as scored by the main reader. The numbers: information (`info`), removable share (`W`), filler and wrong statements (`W_filler`, `W_misleading`), completeness (`kappa`), facts delivered (`facts`), overhead (`overhead`). The fragments (`spans`): decision (`kept`), type (`kind`) and deletion cost (`loo_cost`) |
| `signals.jsonl` | Entropy of the generating model per fragment |
| `reader2_*` | The same scoring with the second reader |
| `filler_check/`, `filler_check_real/` | Checks on planted filler: synthetic reports and real texts. What was planted and what the map deleted |
| `real/human_check/` | The filler map against the human span labels of Poddar et al. |
| `real/filter_report.json`, `real/config.json` | Leakage filter per cell; settings of the run |
| `report/` | Tables as CSV, and figures |
| `synthetic/paper/` | Tables for the paper and a trial sample for annotation |

## Data sources

The real-text items contain texts from public datasets:
- SQuAD 2.0: CC BY-SA 4.0;
- MuSiQue: CC BY 4.0;
- CUAD: CC BY 4.0, The Atticus Project;
- the data of Poddar et al. (2025), github.com/sohampoddar26/LLM-brevity: GPL-3.0.

The synthetic reports are generated by our code.
